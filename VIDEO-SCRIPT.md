# RED ATLAS — Vidéo démo 30 secondes (script de tournage)

## Matériel
- Enregistrement écran : OBS Studio (gratuit) ou l'outil Windows (Win+G)
- Montage : CapCut (gratuit)
- Voix : la tienne en anglais (micro de téléphone suffit), OU voix IA (elevenlabs.io, gratuit)
- Musique : libre de droits, discrète (YouTube Audio Library, "cinematic ambient")

## Le storyboard — plan par plan

### PLAN 1 (0:00–0:05) — L'accroche
- **Image** : écran noir → la phrase apparaît lettre par lettre : *"July 18, 2011. A piece of Mars fell on Morocco."* Puis photo de la météorite Tissint (cherche "Tissint meteorite" sur Google Images, crédite "Meteoritical Bulletin").
- **Voix** : *"In 2011, a Martian meteorite fell on Morocco. We asked NASA's data: where else is Mars hiding?"*

### PLAN 2 (0:05–0:13) — Le moteur qui scanne
- **Image** : capture du site, carte du Maroc → la couche "Engine scan" s'allume (les 159 points colorés apparaissent). Zoom sur les marqueurs dorés (Guelmim–Assa).
- **Voix** : *"We scanned all of Morocco through NASA's POWER API — 159 points — and let machine learning find Mars-analog zones by itself. Its top discovery? A zone nobody had picked."*

### PLAN 3 (0:13–0:21) — La preuve interactive
- **Image** : tu cliques un point au hasard sur la carte (Analyze Anywhere) → la fiche se remplit en direct : MLI, TSI, empreinte, verdict IA. Puis le graphique TSI : barre Maroc = barre Atacama.
- **Voix** : *"Click anywhere on Earth: live NASA data, a Mars Likeness score, and an AI verdict. Morocco's thermal stress equals the Atacama — and M'hamid is hotter than Death Valley."*

### PLAN 4 (0:21–0:26) — La décision
- **Image** : la carte zoome sur l'étoile dorée (site de la station choisi par l'algorithme) → texte à l'écran : *"Atlas Analog Station — engine-selected: 29.3°N, 8.5°W"*.
- **Voix** : *"Our siting algorithm chose where to build the Atlas Analog Station — three hours from Europe, validated by Mars missions that already came."*

### PLAN 5 (0:26–0:30) — Le final
- **Image** : écran noir → logo RED ATLAS + URL du site + QR code (génère-le sur qr-code-generator.com avec ton URL Vercel).
- **Voix** : *"RED ATLAS. The data already knows where. Scan the code — test it yourself."*

## Conseils de tournage
1. Enregistre l'écran en 1080p, site en mode **anglais** (le jury est international)
2. Fais les clics LENTEMENT — le jury doit suivre
3. Sous-titres anglais incrustés (CapCut le fait automatiquement : Text → Auto captions)
4. Exporte en 1080p MP4, moins de 50 Mo si possible
5. Upload sur YouTube (non répertoriée) → colle le lien sur la page projet
